# Lily Lane

Fullscreen Frogger-style hopper. No account. Hop the highway, ride the river, fill every lily pad.

Play: https://lily-lane.netlify.app/lily-lane/

WASD / arrows hop. Esc or P pauses. Swipe or the on-screen pad on a phone.

## What changed from the Grok App Builder build

- Playfield fills the viewport. No rounded 624×624 card.
- Sign in, SSO, and score-posting chrome are gone. Best score stays in localStorage.
- Landing on a log or turtle snaps the frog onto the sprite so it does not hang off the end.
